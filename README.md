Custom C String Library

A custom string-handling project developed in C to implement common string operations from scratch without relying on the standard <string.h> library.

Features

String length

String copy

String comparison

String concatenation

String reverse

Character search

Substring handling

Palindrome checking

Pointer-based string manipulation

Dynamic memory allocation


Technologies

C Programming

Pointers

Arrays

Functions

Dynamic Memory Allocation


Purpose

The project focuses on understanding how string operations work internally and improving knowledge of pointers, memory management, arrays, and low-level C programming.

How to Run

gcc main.c -o string_project
./string_project

Example

Input: VECTOR
Reverse: ROTCEV
Length: 6
Palindrome: No

Learning Outcomes

Strong understanding of C strings and character arrays

Practical pointer manipulation

Better understanding of memory allocation

Implementation of library-like functions from scratch
